# Pelaporan keamanan

Laporkan kerentanan kepada maintainer secara privat beserta dampak dan langkah reproduksi. Jangan publikasikan data finansial, kata sandi, API key, private key Firebase, nilai `FIREBASE_SERVICE_ACCOUNT_BASE64`, atau salinan database.

Repository publik berisi source code saja. Jangan commit `.env`, file service account, database, atau foto struk. Satu deployment menggunakan satu kata sandi bersama; gunakan project Firebase dan kata sandi terpisah untuk setiap pemilik.
